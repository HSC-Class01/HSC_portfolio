# 황세찬 | Portfolio

개인 포트폴리오 웹사이트입니다. 한국어 단일 페이지로 구성되어 있으며, 각 카테고리는 메인 페이지의 상단 메뉴에서 바로 이동할 수 있습니다.

## 카테고리
- **About** — 자기소개와 학업 배경
- **Projects** — AI·데이터 분석 및 재무제표 프로젝트
- **Qualifications & Certifications** — 자격증과 교육 수료 이력
- **Activities** — 봉사활동 및 교내·외 활동

## 실행
별도 빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다.

## 배포
GitHub Pages 사용 시 저장소 Settings → Pages에서 `main` 브랜치의 `/ (root)`를 선택하면 됩니다. Vercel에서는 이 저장소를 Import하고 별도 Build Command 없이 배포할 수 있습니다.

## 디렉터리
- `index.html`: 실제 포트폴리오 페이지
- `sections/`: 카테고리별 소개 및 관리 문서
